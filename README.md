## 💻 Projeto

O Jogo de Dados é um aplicativo desenvolvido para dois jogadores, no qual cada participante realiza lançamentos de dados durante cinco rodadas. Em cada rodada, os jogadores lançam dois dados, e aquele que obtiver a maior soma conquista a vitória.

Ao final das cinco rodadas, o aplicativo apresenta o placar geral e identifica o vencedor da partida, considerando também a possibilidade de empate.

## 🚀 Tecnologias

O projeto foi desenvolvido utilizando:

- **React Native** — Desenvolvimento da interface mobile.
- **Expo** — Plataforma de desenvolvimento e execução.
- **Expo Router** — Gerenciamento da estrutura de navegação.
- **TypeScript** — Linguagem utilizada no desenvolvimento.
- **EAS Update** — Publicação de atualizações Over-the-Air.
- **Git e GitHub** — Versionamento e hospedagem do código-fonte.

## ⚙️ Funcionalidades

- Partida entre dois jogadores.
- Lançamento de dois dados por jogador.
- Valores aleatórios entre 1 e 6.
- Comparação das pontuações em cada rodada.
- Disputa organizada em cinco rodadas.
- Contabilização das vitórias de cada jogador.
- Identificação do vencedor ou empate.
- Exibição do placar final.
- Opção de iniciar uma nova partida.

## 📱 Execução

### Pré-requisitos

- Node.js
- npm
- Expo Go (para execução compatível no dispositivo móvel)

### Instalação

Clone o repositório:

```bash
git clone https://github.com/mateussjose/jogo-dados.git
```

Acesse o diretório:

```bash
cd jogo-dados
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npx expo start
```

Para visualizar no navegador, pressione `W` no terminal.

Para executar no celular, utilize o Expo Go, desde que a versão instalada seja compatível com o SDK utilizado pelo projeto.
